lighthouse-badges

Generate Lighthouse score badges, JSON, or SVG donut charts — straight from your terminal, using local Chrome.

Get Started View on GitHub

Installation

npm install -g lighthouse-badges

Requirements

  • Node.js >= 18.0.0
  • Google Chrome installed on your system

Usage

lighthouse-badges <URL> [options]
OptionDescription
(none)Output Markdown badges
-b, --badgeOutput Markdown badges
-j, --jsonOutput JSON
-s, --svgOutput SVG with donut charts

Examples

Markdown badges (default)

lighthouse-badges https://example.com

JSON output

lighthouse-badges https://example.com -j
{
  "performance": 100,
  "accessibility": 100,
  "bestPractices": 93,
  "seo": 72
}

SVG output

lighthouse-badges https://example.com -s

Badge Colors

ScoreColor
90–100Green
50–89Yellow
0–49Red

Quick Start

Run with Docker

# Production build
docker build -t lighthouse-badges .
docker run lighthouse-badges https://example.com

Run directly

npx github:hidao80/lighthouse-badges https://example.com
